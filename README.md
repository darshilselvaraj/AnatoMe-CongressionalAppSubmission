AnatoMe is plain HTML, CSS, and JavaScript. There are no frameworks and no libraries. The only outside resource is Google Fonts.
The game runs on the HTML Canvas API.

**Running it yourself**
  1) Download or clone this repo.
  2) Open index.html in your browser.

index.html       (Dashboard / start page)
login.html       (Sign in and create an account)
rundown.html     (Warm-up quiz, game, final quiz, and results)
progress.html    (Learner progress page)
script.js        (Dashboard and account logic)
images/          (Skin layer pictures used in the game)
svgs/            (Labeled and unlabeled tissue diagrams)
